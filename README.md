# UpdateWinLTSC

## Usage

Use Win_ISO_Patching_Scripts to automatically integrate Windows 10/11 LTSC updates.

Win_ISO_Patching_Scripts
  <https://github.com/adavak/Win_ISO_Patching_Scripts>

ChangeWindows
  <https://changewindows.org/platforms/pc>
